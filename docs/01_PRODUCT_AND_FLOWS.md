# 01 — Product requirements / User flows

## 제품 목표

행궁동/수원화성 주변의 공공/제휴 화장실을 이용 조건과 함께 안내. 광고 유입 방문객이 화장실을 발견하고 길찾기를 하게 하며, 제휴 가게 등록을 확보한다. 후속으로 **보증금 테스트 결제 → 이용권 → PIN(해당 시) → 영수증 수동 심사 → 테스트 환급**까지 구현한다.

## 역할

- Guest: 로그인 없이 지도/검색/카드/길찾기. 익명 브라우저 ID 이벤트 수집(개인정보 정책 준수).
- Customer: Auth 로그인, 보증금 테스트 결제, 이용권 및 자신의 영수증/환급 상태만 조회.
- Merchant: 로그인, 자신이 소속된 가게만 등록·수정. 등록 무료. PIN 등록/변경은 실제 운영 권한 검증 뒤 가능.
- Admin: 가게 검수, 연락대상 관리, 제휴 시설 승인/중단, 영수증 수동 심사, 테스트 환경 오류 대응. 관리자 권한은 서버/DB에서만 부여.

## 이용자 흐름

1. 광고 UTM 링크로 접근 → 여행 중 여부 응답(기존 H2 적격 식별) → 지도.
2. 공공 화장실 마커 → 위치/개방조건 확인 → 길찾기 클릭 → 외부 카카오맵. 결제 없음.
3. 제휴 화장실 마커 → 실제 가게에서 제공한 조건/보증금/PIN 필요 여부 확인 → 길찾기 클릭 → 별개로 `보증금 결제` 화면 접근.
4. 로그인 → 서버 결제 주문 발행 → Toss 테스트 결제 → 서버 승인 재검증 → 이용권 생성.
5. PIN 시설: 유효한 이용권이면 비밀번호 확인. 비PIN 시설: 직원에게 보여주는 확인 화면 제공.
6. 이용 후 구매한 경우 사진으로 영수증 제출 → 관리자 수동 심사 → 승인 시 PG 테스트 취소 → 사용자에게 환급 상태 표시.
7. 구매하지 않음/기한 초과: 원 결제 유지. 기한·최소 구매금액 등 아직 미확정이므로 테스트 정책을 운영자가 관리하고 라이브 비활성.

**중요**: 길찾기 버튼은 공공/제휴 모두 제공. 길찾기가 결제 필수 조건은 아님. '길찾기' 클릭과 '실제 입장'은 다른 이벤트.

## 가게 흐름

회원가입 → 가게명·주소·연락·사업자/관리권한 증빙(필요 최소 범위) → 가게 등록 → 화장실 시간·위치·조건·사진·PIN 여부 입력 → 관리자 확인 → 지도 공개. 구독료와 PG 가입 없음. 한 가게에 여러 매니저/화장실 가능.

## 운영자 흐름

가게 리드 50곳 관리(접촉 시도 기록) → 등록 신청 검토 → 소유권 검증 → 공개 승인 → 오류신고/긴급중단 → 영수증 심사(승인/반려/재제출) → 테스트 환급 상태 확인 → H1/H2/H5 집계.

## 범위 밖

OCR, 실거래 결제, 크레딧, 구독 청구, 배송/상품 주문, 실시간 스마트락 제어, 출입 사실 자동 검증, 자동 구매취소 탐지, 허위 리뷰/별점 더미, 고객의 모든 위치 이동 내역 저장.

## 누락 주의

정확한 19개 실험 판정 세부 규칙 원문은 이 패키지에 제공되지 않았다. 아는 수치(H1 5/50, H2 5/50, H5 5/50)만 구현 가능하며 19개 규칙 충족을 자동으로 선언하지 않는다.
